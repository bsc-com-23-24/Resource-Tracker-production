
# Resource Tracker Backend Deployment

Ready-to-run Docker deployment for the Resource Tracker backend.

## Docker Image

babylon1340/resource-tracker-api:v1.0.0

## Requirements

- Docker Engine
- Docker Compose

## Quick Start

1. Copy the environment template:

   cp .env.example .env

2. Edit the environment variables.

3. Download and start the application:

   docker compose up -d

4. Check the services:

   docker compose ps

## API Access

Backend: http://localhost:3000

Swagger: http://localhost:3000/api
